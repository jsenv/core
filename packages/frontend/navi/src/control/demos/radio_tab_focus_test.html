Native radio Tab focus test

Pure HTML, no framework. Two independent radio groups (different names), each with a defaultChecked (checked) radio that is not the first one. Tab from the top link through the groups and watch where focus lands (the focus log below records every focus). The question: does the browser Tab to the checked radio of each group, or to the first radio?
