preventDefault matrix — tap-after-drag

Every row is the exact baseline (pointer-driven drag, touch-action: none, overflow: hidden). The only difference is which event(s) get preventDefault(). Touch listeners are attached { passive: false } so the call takes effect; pointer events still drive the drag either way. For each row: drag the grey surface, then within ~300ms tap its button. Green = click fired, red = suppressed. This isolates the minimal preventDefault needed.
