Picker « choisir ou créer »

La façade est un picker classique — chevron quand elle est vide, croix pour la vider — pas un champ de recherche : elle dit ce qui est sélectionné, celle de la surface dit ce qu'on cherche. Le toucher ouvre la surface plein écran. Le + et la dernière ligne de la liste ouvrent le même formulaire de création — le second avec le nom déjà saisi. Les homonymes sont permis : deux personnes peuvent porter le même nom, on les distingue sur le nom de famille ou l'email, deux clubs sur l'adresse. Tape « Damien » pour le voir.
