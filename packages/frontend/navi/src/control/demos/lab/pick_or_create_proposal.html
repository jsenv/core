Picker « choisir ou créer »

La façade du picker est le champ de recherche lui-même. Le toucher ouvre la surface plein écran, qui contient la vraie recherche. L'action de création est juste sous la recherche, toujours présente et inerte tant que rien n'est saisi — même si le nom existe déjà : deux personnes peuvent porter le même nom, on les distingue sur l'email, deux clubs sur l'adresse. Tape « Damien » pour le voir.
