Picker « choisir ou créer »

La façade du picker est le champ de recherche lui-même. Le toucher ouvre la surface plein écran, qui contient la vraie recherche. Le + et la dernière ligne de la liste ouvrent le même formulaire de création — le second avec le nom déjà saisi. Les homonymes sont permis : deux personnes peuvent porter le même nom, on les distingue sur le nom de famille ou l'email, deux clubs sur l'adresse. Tape « Damien » pour le voir.
