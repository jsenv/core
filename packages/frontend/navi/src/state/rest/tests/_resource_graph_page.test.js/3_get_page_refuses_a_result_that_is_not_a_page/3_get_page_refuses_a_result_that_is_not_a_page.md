# [GET_PAGE refuses a result that is not a page](../../resource_graph_page.test.js)

```js
const GAME = resource("game", {
  GET_PAGE: async () => [{ id: 1 }],
});

try {
  await GAME.GET_PAGE({ start: 0, limit: 10 });
  return "no error";
} catch (e) {
  return e.message;
}
```

```js
game.GET_PAGE must return { items, start, count }, received an array of 1 item.
```
